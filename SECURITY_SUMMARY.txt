   -> Duration: Max 30 days of data

3. Network Transmission (to Backend):
   -> HTTPS to https://cyclingecg.onrender.com [OK]
   -> HTTP to http://192.168.1.100:8000 [BAD]
   -> POST /v1/ecg/analyze with raw samples
   -> Authorization: Bearer [API_KEY from UserDefaults]

BACKEND:
--------
1. Data Processing:
   -> Receives raw ECG samples
   -> Extracts features (HR, HRV, rhythm classification)
   -> Generates analysis results
   -> Discards raw samples (doesn't store them) [GOOD]

2. Data Storage:
   -> Features stored in SQLite database [UNENCRYPTED]
   -> Full analysis JSON stored [UNENCRYPTED]
   -> 30-day statistics calculated and stored [UNENCRYPTED]
   -> Indefinite retention (no deletion policy) [BAD]

3. Optional AI:
   -> Sends health metrics to OpenAI API
   -> OpenAI not HIPAA compliant
   -> No user disclosure when enabled
